# Data

`telco_churn.csv` is the IBM Telco Customer Churn sample dataset (7,043 subscribers, 21 columns, 26.5% churn).
Source: https://github.com/IBM/telco-customer-churn-on-icp4d (data/Telco-Customer-Churn.csv).

`sample_input.csv` holds 200 unseen test customers (no target column) plus three deliberately messy rows
(negative tenure, an unseen payment method, missing optional fields) for trying the batch CLI.
